01 · Limit

数列极限：从“越来越近”到严格定义

先用人话理解

当 n 不断增大，数列 aₙ 的值越来越靠近 A，并且无论要求多小的误差，后面的所有项都能进入这个误差范围，就称 aₙ 收敛于 A。

limn→∞ aₙ = A

ε-N 定义

对任意 ε>0，总存在正整数 N，使得当 n>N 时，都有：

|aₙ − A| < ε
顺序不能反：先由别人给出任意小的 ε，再根据 ε 找到合适的 N。
图 1：数列最终进入 A±ε 的误差带，并不再跑出去

例：证明 aₙ=1/n 的极限是 0

1
目标是让 |1/n−0|<ε，也就是 1/n<ε。
2
把不等式变形为 n>1/ε，因此只需取 N>1/ε。
3
当 n>N 时，1/n<1/N<ε，所以 limn→∞1/n=0。
易错点：N 不需要等于 1/ε，只要选取一个比 1/ε 大的正整数即可。

02 · Epsilon–Delta

函数极限：x 靠近 x₀ 时，f(x) 靠近 A

函数极限关注 x 在 x₀ 附近时的表现，通常不要求 x=x₀，甚至 f(x₀) 可以没有定义。

ε-δ 定义

对任意 ε>0，总存在 δ>0，当 0<|x−x₀|<δ 时，都有：

|f(x) − A| < ε
  • ε 控制函数值离 A 有多近
  • δ 控制 x 要离 x₀ 多近
  • 0<|x−x₀| 表示只看附近，不看 x₀ 本身
直观理解：先在纵轴上给一条很窄的目标带 A±ε，再在横轴上找一个范围 x₀±δ，保证函数图像落进目标带。
图 2：横向 δ 范围对应纵向 ε 误差带

左右极限

左极限
limx→x₀⁻ f(x)

从 x₀ 左侧靠近，只观察左边。

右极限
limx→x₀⁺ f(x)

从 x₀ 右侧靠近，只观察右边。

极限存在的充要条件：左极限和右极限都存在，并且二者相等。

极限计算：先识别结构，再选方法

必背 1

两个重要极限

limx→0 sin x / x = 1
limx→∞ (1+1/x)x = e

遇到三角函数、幂指函数时，先观察能否通过换元或拆项凑出这两种标准形式。

必背 2

常用等价无穷小

x→0 时

sin x ~ x　tan x ~ x
ln(1+x) ~ x　eˣ−1 ~ x
1−cos x ~ x²/2

只用于乘除：加减结构里直接替换，可能把主项抵消掉，导致结果错误。

04 · Convergence

收敛判定：夹逼与单调有界

夹逼定理

若 g(x)≤f(x)≤h(x)，且 g、h 都趋于 A，则 f 也趋于 A。

g ≤ f ≤ h，lim g = lim h = A
⇒ lim f = A

适用：正面算不动，但容易估出上下界的求和式、三角式。

图 4：上下界趋于同一值，中间函数被“夹”过去

单调有界准则

单调递增且有上界，或单调递减且有下界的数列，一定收敛。

单调 + 有界 ⇒ 收敛

适用：递推数列没有通项，先证明极限存在，再对递推式两边取极限求值。

图 5：一直上升但被上界挡住，因此必有极限
夹逼易错：放缩过松会导致上下界极限不同，定理失效。
单调有界易错：只证明单调或只证明有界都不够，两个条件缺一不可。

Continuity

连续：有定义、极限存在、两者相等

01

有定义

f(x₀) 必须有具体函数值。

02

极限存在

左右极限存在且相等。

03

值相等

lim f(x)=f(x₀)。

f 在 x₀ 连续 ⇔ limx→x₀ f(x) = f(x₀)

四类常见间断点

左右极限相等，但函数值缺失或不等
左右极限都存在，但不相等
至少一侧极限趋于无穷
无限振荡，极限不存在
判断顺序：先算左极限、再算右极限；两者相等再检查函数值。这个顺序适用于所有分段函数连续性题。

极限计算与收敛判定

题 1 · 等价无穷小

典型计算题 · 8分

求：limx→0 [1−cos x] / [x·sin x]

1
识别为 0/0 型，整体是乘除结构，可以使用等价无穷小。
2
当 x→0 时，1−cos x ~ x²/2，sin x ~ x。
3
原式 ~ (x²/2)/(x·x)=1/2，所以极限为 1/2。
易错：不能只替换分子的一部分；要保证替换发生在整体乘除关系中。

题 2 · 单调有界准则

递推数列 · 12分

已知 a₁=1，aₙ₊₁=√(2+aₙ)，证明数列收敛并求极限。

1
证有界：用归纳法可证 1≤aₙ<2。
2
证单调：aₙ₊₁−aₙ=(2+aₙ−aₙ²)/(√(2+aₙ)+aₙ)>0，因此单调递增。
3
单调递增且有上界，故数列收敛。设极限为 A。
4
对递推式取极限：A=√(2+A)，解得 A=2 或 −1；结合 A≥1，故 A=2。

分段函数的连续性

题 3 · 求参数使函数连续

高频题 · 10分

设函数：

f(x) = { (eˣ−1)/x，x≠0；　a，x=0 }

求参数 a，使 f(x) 在 x=0 处连续。

解题思路：连续三条件逐项检查

1
有定义：f(0)=a，条件满足。
2
极限存在：limx→0(eˣ−1)/x=1，左右极限相等。
3
值相等：要连续，必须 limx→0f(x)=f(0)，因此 a=1。
答案：a=1。此时原本的可去间断点被补上，函数在 x=0 处连续。
a≠1 时，函数值没有落在极限位置
a=1 时，函数值等于极限值
考场提醒：遇到“求参数使连续”，本质都是让分界点左右极限、极限值与函数值三者相等。

本章小结
Summary

复习到这里，至少带走四件事

01

定义：把“趋近”说严格

数列用 ε-N，函数用 ε-δ。记住先给误差，再找界限；函数极限只看附近，不一定看该点。

02

计算：先看结构，再选方法

确定型直接代入；0/0 或 ∞/∞ 先化简、等价无穷小或洛必达；幂指型优先取对数。

03

判定：算不出时证明它收敛

能估上下界用夹逼；递推数列常用单调有界，先证存在，再把极限代回递推式求值。

04

连续：三个条件缺一不可

有定义、极限存在、极限值等于函数值。间断点先看左右极限，再看函数值。

考前自检

□ 能说清 ε 和 N/δ 谁先谁后
□ 会背两个重要极限
□ 知道等价无穷小不能用于加减
□ 会用夹逼处理求和式
□ 会证明递推数列单调且有界
□ 会判断四类间断点
最后一句：极限是后续导数与积分的共同基础。定义决定理解深度，计算决定考试分数，连续性则把极限真正接到函数上。
